# SnapLong

SnapLong 是一款 Edge 浏览器长截图扩展。它可以滚动截取整页或指定滚动面板，自动拼接截图，并导出 PNG、JPEG 或 PDF。

**当前正式版：**[v1.3.1](https://github.com/Ludy258/SnapLong/releases/tag/v1.3.1) - 稳定性与界面优化。

## 功能

| 功能 | 说明 |
|---|---|
| 整页长截图 | 自动滚动，结合重叠区域匹配完成拼接。 |
| 可视区域截图 | 立即保存当前浏览器视口。 |
| 多滚动区域截图 | 选择多个独立滚动面板，分别截取后合成为一张图片。 |
| 上下文合成 | 截取自定义面板时保留页眉、页脚、侧边栏等页面内容。 |
| 多种导出格式 | 支持 PNG、JPEG 和分页 PDF。 |
| 截图控制 | 可调延迟、保存目录、另存为提示，以及浅色、深色和自动主题。 |

## 安装

1. 从[最新 Release](https://github.com/Ludy258/SnapLong/releases/latest)下载 `SnapLong-extension.zip`。
2. 解压到本地文件夹。
3. 在 Edge 打开 `edge://extensions`，开启**开发人员模式**。
4. 点击**加载解压缩的扩展**，选择解压后的扩展目录。

## 使用

1. 打开目标网页，点击 SnapLong 图标，或按 `Ctrl+Shift+S`。
2. 等待弹窗完成页面尺寸检测。
3. 选择导出格式和滚动延迟，然后点击**截取长图**。
4. 默认会保存到 `~/Downloads/SnapLong/`。

截图期间请保持目标标签页处于活动状态。浏览器仅允许对当前可见标签页进行截图。

## 多滚动区域

当 SnapLong 检测到多个符合条件的滚动区域时，弹窗会显示“滚动区域”列表。

1. 使用右侧开关决定哪些区域参与截图。
2. 使用左侧圆点选择主容器。
3. 主容器决定最终合成图的高度；默认会选择滚动高度最大的区域。
4. 截取自定义面板且希望保留周边页面内容时，开启“保留固定页眉与页脚”。

此模式最适合仪表盘、编辑器和分屏工作台这类**并列且独立**的面板。对于嵌套或彼此重叠的滚动区域，请只选择真正需要的一个容器；父容器滚动时，子容器的页面坐标并不稳定，同时截图会产生内容重叠。

## 工作原理

```text
弹窗
  -> 内容脚本检测滚动区域并生成截图计划
  -> Service Worker 滚动每个选中区域并捕获帧
  -> Offscreen Document 裁剪、拼接并合成图片
  -> 浏览器下载导出文件
```

- Service Worker 将 `captureVisibleTab()` 限制为每 500 ms 一次，并会重试失败的截图。
- 每个选中的滚动区域都有独立的滚动计划和拼接结果。
- 成功、失败或中断后，扩展都会恢复原始滚动位置和临时隐藏的固定元素。

## 已知限制

- 浏览器 Canvas 存在尺寸限制：单边不能超过 32,767 px，最终画布约限制在 268 MP。
- 多区域截图的耗时约等于所有区域帧数之和乘以所选延迟。
- PDF 是光栅化输出，内容不可作为文本选择。
- 如果页面在截图期间动态移动或调整面板尺寸，预先计算的裁剪位置可能失效。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+S` | 打开 SnapLong 弹窗 |
| `Alt+Shift+S` | 用当前默认设置一键截取长图 |

可在 `edge://extensions/shortcuts` 修改快捷键。

## 开发

```powershell
# 在 edge://extensions 中加载 edge-extension 目录。

# 打包发布文件。
Compress-Archive -Path 'edge-extension/*' -DestinationPath 'SnapLong-extension.zip' -Force
```

项目使用 Manifest V3、负责截图协调的 Service Worker、负责图像处理的 Offscreen Document，以及原生 JavaScript。当前代码不包含统计服务或后端接口，截图数据仅在浏览器扩展中处理并下载到本地。
